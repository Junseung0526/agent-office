# 🏢 에이전트 오피스 (Agent Office)

> **Claude Code / Antigravity**가 남기는 실시간 세션 기록(JSONL)을 **0.25초마다 읽어**, AI 에이전트가 지금 무슨 일을 하고 있는지 **픽셀아트풍 사무실 속 캐릭터의 움직임**으로 시각화하는 로컬 웹 대시보드입니다.

---

## ⚡ 빠른 시작 (3가지 실행 방법)

외부 패키지 설치(`npm install` 등)가 **전혀 필요 없습니다**. Node.js만 설치되어 있다면 즉시 실행할 수 있습니다:

### 방법 A. 가장 편한 방법 (더블클릭 실행)
Finder에서 **`에이전트오피스.command`**를 더블클릭하세요!
- 서버가 켜져 있지 않으면 백그라운드로 띄우고 브라우저를 즉시 엽니다.
- 이미 켜져 있으면 바로 대시보드 창만 엽니다.

### 방법 B. 백그라운드 관리 스크립트 (`office.sh`)
터미널에서 백그라운드 서비스로 제어할 수 있습니다:
```bash
./office.sh start --open     # 백그라운드 실행 후 브라우저 열기
./office.sh status           # 서버 상태 및 PID 확인
./office.sh stop             # 서버 종료
./office.sh restart          # 서버 재시작
./office.sh logs             # 실시간 로그 확인
./office.sh make-app         # Dock 등록용 macOS 네이티브 AgentOffice.app 생성
```

### 방법 C. 로그인 시 백그라운드 자동 실행 (선택)
컴퓨터를 켤 때마다 자동으로 에이전트 오피스가 백그라운드에서 돌게 하려면:
```bash
./office.sh install-autostart      # LaunchAgent 설정 내용 확인 후 y/N 등록
./office.sh uninstall-autostart    # 자동 실행 등록 해제
```

## 🎮 주요 기능

### 1. 픽셀아트 그래픽 & 오프스크린 베이킹 엔진
- **480×270 네이티브 픽셀 해상도**: 정수 2x 배율(960×540)로 선명하게 스케일링하며 `imageSmoothingEnabled = false`로 고전 도트 감성을 완벽 구현했습니다.
- **오프스크린 스프라이트 베이킹**: 매 프레임 도형을 계산하지 않고, 시작 시 32색 마스터 팔레트 기반의 문자열 맵을 오프스크린 캔버스에 구워두어 `drawImage`로 60FPS를 가볍게 유지합니다.
- **방마다 5개 이상의 정교한 소품 배치**:
  - **자료실**: 책 색상이 제각각인 원목 책장, 독서대, 목재 사다리, 녹색 갓등 스탠드, 앤틱 카드 서랍장
  - **개발실**: 줄 단위 코드 스크롤 및 문법 하이라이트가 번쩍이는 아이맥, 키보드, 모락모락 김이 피어오르는 머그잔, 몬스테라 화분, 포스트잇
  - **서버실**: 19인치 서버 랙 2대, 바닥 에어벤트 환풍구 메탈 그릴, 케이블 다발, 점멸 LED, 상단 비상 회전 경고등
  - **정보검색실**: 듀얼 모니터 벽, 황동 데스크 지구본, 레이더 돋보기 스캔 연출, 무선 안테나 라우터
  - **회의실**: 실제 시간대(낮/노을/밤하늘 및 별/도시 야경) 연동 창문, 체크리스트 화이트보드, 원탁 테이블 및 바퀴 달린 회의 의자
  - **내 자리**: 원목 책상과 노트북, 웜 옐로우 스탠드 조명, 사용자 의자, **질문 도착 시 책상 위 알림 아이콘(!) 바운스 점멸**
- **대기/환경 연출**: 공기 중 부유하는 픽셀 먼지 입자, 복도 비상구(EXIT) 초록 유도등, 체커보드 바닥 디더링 패턴

### 2. 백화점 층별 안내 사이드바 (최고층 ➔ 1F 역순 정렬)
- **최신 활동 = 최고층 (Top Floor)**: 가장 최근에 활동한 프로젝트가 사이드바 맨 위(최고층)에 위치하며, 가장 오래된 프로젝트가 1F(맨 아래)에 위치합니다.
- **프로젝트(CWD) 세션 통합**: 같은 CWD를 가진 세션들은 수십 개가 있어도 정확히 하나의 층으로 통합됩니다. (예: notion MCP 14개 세션 ➔ 1개 층으로 묶임)
- **첫 접속 시 자동 선택**: 웹페이지를 열면 가장 최근에 작업한 최고층 프로젝트가 기본으로 선택됩니다.

### 3. 사무실 방별 "지금 하는 일" 구체적 실시간 표시
도구 호출 인자(`args` / `input`)에서 핵심 파라미터를 정밀 추출하여 각 방의 소품 위에 고해상도 라벨로 실시간 표시합니다:
- **개발실 (Dev)**: 수정 중인 파일명 (경로 제외 마지막 파일명만)을 아이맥 모니터 위 작은 배지에 표시 (예: `📄 server.js`)
- **서버실 (Server)**: 실행 중인 명령어 앞 30자 정도를 랙 위 작은 **전자 전광판에 흐르는 글자(Marquee)**로 표시 (예: `> npm test -- --watch`)
- **자료실 (Archive)**: 읽는 파일명 또는 검색어/패턴을 책상 위 카드 라벨에 표시 (예: `📖 app.log`, `🔍 grep: handleClick`)
- **정보검색실 (Research)**: 검색어 또는 MCP 도구 이름을 모니터 위에 표시 (예: `🔍 검색: pixel art`, `⚡ MCP: notion_search`)
- **부드러운 페이드아웃**: 도구 작업이 완료되면 라벨은 **1초 동안 유지된 뒤 0.8초에 걸쳐 자연스럽게 페이드아웃**됩니다.
- **보안 마스킹 (Security)**: 명령어/인자에 포함된 토큰이나 비밀번호(`KEY=`, `TOKEN=`, `password=`, `Bearer`, `ghp_`, `sk-` 등)는 화면에 노출되지 않도록 사전에 **`***`로 자동 마스킹**됩니다.
- **설정 분리**: `public/index.html` 상단의 `TOOL_PARAM_MAPPINGS` 객체에서 도구별 추출 규칙과 필드명을 쉽게 커스터마이징할 수 있습니다.

### 4. 사무실 구조 (방 = 도구 종류)
| 방 | 도구 매핑 예시 | 연출 |
|---|---|---|
| **자료실** | `Read`, `Grep`, `Glob`, `LS`, `view_file`, `read_resource` 등 | 원목 책장 선반 앞에서 책을 펴고 읽음 (책상 위 파일/검색어 라벨) |
| **개발실** | `Edit`, `Write`, `MultiEdit`, `write_to_file`, `replace_file_content` | 아이맥 화면에 코드가 흐르며 모니터 위 수정 파일명 표시 |
| **서버실** | `Bash`, `run_command`, `terminal`, `git` | 랙 앞 작업. 랙 위 초록색 LED 전광판에 명령어가 흐름 |
| **정보검색실** *(기본값)* | `WebSearch`, `WebFetch`, `search_web`, `call_mcp_tool`, 기타 미분류 도구 | 모니터 벽과 레이더 스크린 위 검색어/MCP 도구명 표시 |
| **회의실** | `TodoWrite`, `TodoRead`, `plan`, `manage_task`, `schedule` | 대형 화이트보드에 체크리스트와 포스트잇이 붙음 |
| **내 자리** | `AskUserQuestion`, `ask_question`, 권한 승인 대기 | 사용자 노트북 앞까지 걸어와서 노란 말풍선으로 질문 |
| **엘리베이터** | `invoke_subagent`, `Agent`, `Task` 등 | 서브에이전트 캐릭터가 타고 출근하고, 작업 종료 시 퇴근 |

> **도구 매핑 설정**: `server.js` 상단의 `TOOL_ROOM_MAP` 객체에서 언제든 쉽게 수정할 수 있습니다. 매핑에 없는 도구는 기본적으로 **"정보검색실"**로 배치됩니다.

### 5. 캐릭터 상태 머신
- **도구 호출 시작 (`tool_start`)**: 목적지 방으로 뚜벅뚜벅 걸어가서 작업 모션(타이핑, 독서, 랙 점검 등) 시작
- **도구 결과 도착 (`tool_end`)**: 작업 모션 종료 후 대기 자세 복귀 (방 라벨은 1초 뒤 페이드아웃)
- **생각 중 (`thinking`)**: 머리 위에 몽글몽글 구름 모양 말풍선 💭 과 요약 텍스트 표시
- **막힘/고민 (`pondering`)**: 3.5초 이상 새 이벤트 없이 생각 중이면 그 자리에서 턱을 괴고 고민하는 포즈 (? 이모션)
- **도구 실패 (`error`)**: 식은땀 이모션 💦 + 빨간색 경고 말풍선 ⚠️ 에러 요약
- **서브에이전트 위임 (`subagent_spawn`)**: 주황색 옷을 입은 서브에이전트가 엘리베이터 문을 열고 출근하여 해당 방으로 이동
- **일 종료 / 턴 완료 (`turn_finish`)**: 사용자 앞쪽으로 걸어와서 "업무 완료 보고서" 📋 제시 후 "퇴근합니다!" 인사와 함께 엘리베이터를 타고 슝 사라짐
- **사용자 질문 (`ask_user`)**: 내 자리 책상 앞까지 찾아와 질문 말풍선 💬 제시

### 6. 스마트 알림 시스템
- **알림 트리거**: 내 응답 필요(질문 대기), 작업 완료(턴 종료), 동일 세션 도구 3회 연속 실패
- **알림 채널**: 백그라운드 탭 제목 교차 점멸, 브라우저 데스크톱 알림 (Notification API, 수동 🔔 토글 시 1회 권한 요청), Web Audio 사운드 연동
- **층별 ❓ 노란색 배지**: 보고 있지 않은 다른 층에서 질문이 발생하면 해당 층 카드에 ❓ 배지가 표시되며, 해당 층 방문 시 자동 해제됩니다.

### 7. 8-Bit 레트로 사운드 (Web Audio API)
- 외부 오디오 파일 다운로드 없이 브라우저 내장 Web Audio API로 실시간 발소리, 키보드 타이핑, 에러 비프음, 딩동 및 팡파레 효과음을 합성합니다. (상단 우측 버튼으로 On/Off 가능)

### 8. 세션별 토큰 사용량 미터 & 코인 저금통 (실제 로그 기반)
- **실제 로그 구조 기반 수집**: Claude Code(`message.usage`의 `input_tokens`, `output_tokens`, `cache_*`)와 Antigravity(`PLANNER_RESPONSE`의 토큰 필드)의 중복을 자동 제거하고 실시간 누적 집계합니다.
- **데이터 없는 엔진 자동 숨김**: 토큰 정보가 없는 세션(추정 불가)은 상태 패널의 미터와 캔버스 저금통/코인을 완전히 숨겨 노이즈를 방지합니다.
- **내 자리 코인 저금통 연출**: 내 자리 책상 위에 7x6 핑크 돼지 저금통이 놓이며, 누적 토큰 1만 개당 황금 코인이 1개씩 층층이 쌓입니다 (최대 14개 제한, 2개 스택 분할). 상단에는 선명한 네이티브 코인 뱃지가 표시됩니다.
- **하단 상태 패널**: `입력 / 출력 / 캐시 / 총합` 토큰 숫자와 모델명을 깔끔한 그리드로 표시합니다.
- **모델별 단가(비용 환산) 설정 분리**: 코드 상단 `TOKEN_PRICE_CONFIG` 객체에 모델별 단가를 기입할 때만 예상 비용($)을 계산하여 표시합니다 (기본값은 null로 비용 미표시).
