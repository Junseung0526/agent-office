# 에이전트 오피스 (Agent Office)

> 로컬 인공지능 에이전트 실시간 활동 관제 및 픽셀아트 시각화 대시보드

에이전트 오피스(Agent Office)는 **Claude Code** 및 **Antigravity CLI** 엔진이 로컬 환경에서 생성하는 세션 트랜스크립트 로그를 실시간으로 스트리밍 분석하여, 에이전트의 현재 작업 상태와 도구 호출 내역을 픽셀아트 가상 오피스 환경에 투영하는 고성능 경량 관제 솔루션입니다.

외부 패키지 의존성(npm/pip)과 빌드 과정이 전무한 순수 Node.js 표준 라이브러리 기반으로 설계되었으며, 루프백(127.0.0.1) 전용 바인딩과 엄격한 보안 마스킹 정책을 적용하여 민감 정보 유출 위험 없이 안전하게 동작합니다.

## 핵심 기능

### 1. 실시간 무지연 이벤트 스트리밍 (SSE)
- 파일 시스템 변경 이벤트(`fs.watch`)와 적응형 폴링(활성 250ms / 대기 2,000ms)을 결합한 하이브리드 파일 테일링(Tailing) 엔진 탑재
- Server-Sent Events (SSE) 기반 단방향 실시간 이벤트 브로드캐스트
- 500개 용량의 서버 인메모리 링 버퍼 및 `Last-Event-ID` 기반 재연결 패킷 손실 자동 복원 메커니즘 제공
- 신규 클라이언트 접속 시 최근 30개 이벤트를 리플레이 플래그와 함께 즉시 동기화

### 2. 고성능 2패스 반응형 그래픽 엔진
- **Pass 1 (픽셀아트)**: 480x270 네이티브 해상도의 1x 정수 도트 그래픽을 오프스크린 캔버스에 렌더링한 후 메인 캔버스에 최근접 이웃(Nearest-Neighbor) 보간으로 확대 투영
- **Pass 2 (선명한 벡터 텍스트)**: `devicePixelRatio`를 반영한 물리 버퍼 해상도 상에서 960x540 논리 좌표계 기반 한글 벡터 타이포그래피 래스터라이징 수행 (고해상도 디스플레이 및 모바일 선명도 100% 보장)
- `ResizeObserver` (100ms 디바운스)를 통한 16:9 종횡비 컨테이너 적응형 자동 스케일링

### 3. 멀티 세션 계층화 및 층별 안내 사이드바
- 동일한 작업 디렉터리(CWD)를 공유하는 세션들을 단일 논리 층(Floor)으로 자동 병합
- 최종 활동 타임스탬프 기준 최고층(Top Floor) 내림차순 자동 정렬
- DOM 노드 파괴를 방지하는 키 기반 차등 갱신(Diff-based Update) 알고리즘 적용

### 4. 실제 트랜스크립트 기반 토큰 및 비용 계측
- Claude Code (`message.usage`) 및 Antigravity (`PLANNER_RESPONSE`)의 원본 토큰 필드 수집
- 입력(Input), 출력(Output), 캐시(Cache) 토큰의 중복 없는 누적 집계
- 작업 공간 내 물리적 코인 저금통 픽셀아트 시각화 (1만 토큰당 코인 1개 적재, 최대 14개) 및 실시간 사용량 메트릭 패널 제공

### 5. 엔터프라이즈 데스크톱 알림 및 레트로 사운드
- 사용자 개입 필요(질문 대기), 작업 완료 보고, 동일 도구 연속 실패 등 임계 이벤트 발생 시 데스크톱 브라우저 푸시 알림(Web Notifications API) 발송
- 백그라운드 탭 타이틀 교차 점멸 및 비활성 층 경고 배지 표시
- 외부 오디오 에셋 다운로드 없이 Web Audio API를 활용한 순수 절차적(Procedural) 8-Bit 신시사이저 사운드 실시간 합성

### 6. 인터랙티브 인스펙터 및 마크다운 세션 리포트
- **룸 및 캐릭터 클릭 인스펙터**: 캔버스 상의 각 룸 또는 캐릭터 클릭 시 사이버펑크 글래스모피즘 모달을 통해 비절단 전체 파일 경로, 터미널 실행 명령어, 1-Click 클립보드 복사, 룸별 작업 이력 타임라인 제공
- **1-Click 마크다운 업무 보고서 복사**: 프로젝트 개요, 현재 상태, 토큰 사용량 및 룸별 최근 수행 내역을 구조화된 Markdown 형식으로 즉시 클립보드 복사
- **엔진별 고유 외형 차별화**: Claude Code(테라코타 오렌지 코트 및 퍼플 타이)와 Antigravity(사이언 블루 랩코트 및 네이비 타이) 캐릭터 복장 고유 베이킹

### 7. 24시간 실시간 환경 조명 사이클 및 레트로 CRT 모드
- **24시간 시스템 시각 연동 앰비언트 라이팅**: 실제 시스템 시각을 기반으로 새벽(쿨 퍼플), 주간(선명한 클리어), 일몰(따뜻한 앰버), 심야(깊은 미드나잇 틴트 및 서버실/개발실/데스크 포인트 라이트 발광) 조명 연출
- **레트로 CRT 스캔라인 모드**: 아케이드 모니터 특유의 미세 3px 스캔라인, RGB 애퍼처 그릴, 방사형 비네팅 섀도우 마스크를 하드웨어 가속 CSS 오버레이로 제공 (토글 상태 영구 보관)

### 8. 실시간 토큰 소모율(Burn Rate) 네온 스파크라인
- 토큰 미터 패널 내 초당 토큰 소모량(tok/s) 실시간 산출 및 2D 캔버스 네온 영역 그래프 렌더링
- 슬라이딩 윈도우 기반 동적 스케일링, 네온 그라디언트 에어리어 필 및 엔드포인트 펄스 닷 표시

## 실행 및 운영 가이드

### 환경 요구사항
- **Runtime**: Node.js v18.0.0 이상 (v20+ 권장)
- **OS**: macOS, Linux, Windows (macOS 환경에 최적화된 실행기 포함)
- **Browser**: Chrome, Safari, Firefox, Edge 등 최신 모던 브라우저
- **Dependencies**: 순수 표준 라이브러리 전용 (외부 패키지 의존성 없음)

### 실행 방법

#### 1. 대화형 실행 스크립트 (macOS GUI)
Finder에서 `에이전트오피스.command` 파일을 더블클릭합니다.
- 서비스가 기동 중이지 않은 경우 백그라운드 데몬으로 실행하고 기본 브라우저를 즉시 호출합니다.
- 서비스가 이미 동작 중인 경우 기존 인스턴스를 유지하며 대시보드 창만 새 탭으로 연결합니다.

#### 2. 터미널 서비스 매니저 (`office.sh`)
CLI 환경에서 데몬 상태 및 로그를 제어할 수 있습니다:
```bash
./office.sh start --open     # 백그라운드 서비스 시작 및 브라우저 열기
./office.sh status           # 서비스 프로세스 상태 및 PID 확인
./office.sh stop             # 서비스 정상 종료
./office.sh restart          # 서비스 재기동
./office.sh logs             # 실시간 표준 입출력 로그 스트리밍
./office.sh make-app         # macOS 네이티브 바로가기 앱(AgentOffice.app) 생성
```

#### 3. 운영체제 부팅 시 자동 기동 (macOS LaunchAgent)
사용자 로그인 시 백그라운드 서비스로 자동 실행되도록 등록할 수 있습니다:
```bash
./office.sh install-autostart      # LaunchAgent 명세 확인 후 등록
./office.sh uninstall-autostart    # LaunchAgent 등록 해제
```

#### 4. 독립 창(Standalone Application) 모드 설정
브라우저 툴바 없이 독립된 데스크톱 위젯 형태로 사용할 수 있습니다:
- **Google Chrome**: 우측 상단 옵션 메뉴 -> **저장 및 공유** -> **에이전트 오피스 설치...** (또는 바로가기 만들기 -> '창으로 열기' 활성화)
- **Safari**: 파일 메뉴 -> **Dock에 추가...** -> 이름 확인 후 등록

## 렌더링 파이프라인 및 그래픽 엔진

대시보드 렌더링 엔진은 도트 그래픽의 레트로 질감 유지와 CJK(한글) 벡터 타이포그래피의 가독성을 동시에 만족하기 위해 분리된 2패스 파이프라인을 운용합니다.

```
[Logical Tick Event]
        |
        v
+-----------------------------------------------------------------------+
| Pass 1: 480x270 Offscreen Dot Canvas                                  |
| - Environment Background & Pre-baked Corridor Floor                   |
| - Pixel Props & Time-based Sky Light Cycle (Day/Sunset/Night)         |
| - Character Dot Animations & Action Poses (Idle, Walk, Type, Ponder)  |
+-----------------------------------------------------------------------+
        |
        | ctx.imageSmoothingEnabled = false
        | ctx.drawImage(dotCanvas, 0, 0, bufferW, bufferH)
        v
+-----------------------------------------------------------------------+
| Intermediate Physical Buffer (Scaled by nearest-neighbor)             |
+-----------------------------------------------------------------------+
        |
        | ctx.scale(bufferW / 960, bufferH / 540)
        | ctx.imageSmoothingEnabled = true
        v
+-----------------------------------------------------------------------+
| Pass 2: High-DPI Vector Typography (960x540 Logical Coordinates)      |
| - Room Neon Signs & Real-time Task Detail Badges                      |
| - Server Marquee Ticker                                               |
| - Vector Speech Bubbles (Think, Tool, Ask, Error)                     |
| - High-precision Character Role Labels                                |
+-----------------------------------------------------------------------+
```

### 반응형 뷰포트 처리 명세
- **1100px 이상**: 260px 폭의 층별 안내 사이드바, 960x540 캔버스, 3분할 가로 상태 패널 유지
- **700px ~ 1100px (태블릿)**: 사이드바를 68px 폭으로 축소하여 층수 및 상태 표시등 중심으로 컴팩트 렌더링, 상세 정보는 툴팁으로 제공
- **700px 미만 (모바일)**: 사이드바를 상단 가로 스크롤 칩 네비게이션으로 전환하고 캔버스를 전체 폭(100%)으로 확장. 하단 패널은 키보드 및 터치 접근성을 만족하는 아코디언 접이식 인터페이스로 전환
- **320px 하한선 보장**: 패딩 축소 및 텍스트 자동 말줄임 처리를 통해 320px 폭 환경에서도 수평 스크롤이 발생하지 않음

## 사무실 구역 및 도구 매핑 체계

실행되는 도구의 역할과 성격에 따라 캐릭터가 해당 사무실 구역으로 이동하여 고유한 모션을 수행합니다:

| 구역 명칭 | 주요 매핑 도구 | 시각 연출 및 작업 정보 표시 |
| :--- | :--- | :--- |
| **자료실** (Archive) | `Read`, `Grep`, `Glob`, `LS`, `view_file`, `read_resource` 등 | 책장 선반 앞 열람 모션. 책상 상단에 파일명 또는 검색 패턴 카드 표시 |
| **개발실** (Dev) | `Edit`, `Write`, `MultiEdit`, `write_to_file`, `replace_file_content` | 아이맥 모니터 앞 키보드 타이핑 모션. 수정 대상 파일명 배지 렌더링 |
| **서버실** (Server) | `Bash`, `run_command`, `exec`, `terminal`, `sh`, `zsh`, `git` | 서버 랙 앞 점검 모션. 랙 상단 전광판에 명령어 흐름(Marquee) 표시 |
| **정보검색실** (Research) | `WebSearch`, `WebFetch`, `search_web`, `call_mcp_tool`, 미분류 도구 | 듀얼 모니터 및 레이더 스크린 모션. 검색어 또는 MCP 서비스명 표시 |
| **회의실** (Meeting) | `TodoWrite`, `TodoRead`, `plan`, `manage_task`, `schedule` | 대형 화이트보드 앞 기획 모션. 작업 보고서 제출 및 턴 종료 집결지 |
| **내 자리** (User Desk) | `AskUserQuestion`, `ask_question`, 권한 승인 대기 인터랙션 | 사용자 노트북 앞으로 이동하여 질문 말풍선 및 알림 점멸 연출 |
| **엘리베이터** (Elevator) | `invoke_subagent`, `Agent`, `Task` 등 | 에이전트 출퇴근 및 서브에이전트 게이트 애니메이션 |

*매핑 규칙은 `lib/config.js`의 `TOOL_ROOM_MAP` 객체에서 설정할 수 있습니다.*

## 상태 머신 및 생명주기 관리

캐릭터의 동작은 10단계 상태 머신으로 통제되며, 비동기 레이스 컨디션 및 데드락을 방지하는 안전 메커니즘을 내장하고 있습니다:

```
[IDLE] <-------------------+-----------------------+
   |                       |                       |
   | (tool_start)          | (auto-recovery / 5s)  | (timeout cancel)
   v                       |                       |
[WALKING] ---> [WORKING]   |                   [REPORTING]
   |              |        |                       ^
   | (arrived)    | (error)|                       | (turn_finish)
   v              v        |                       |
[THINKING]     [ERROR] ----+                   [WORKING / IDLE]
   |                                               |
   | (idle > 3.5s)                                 v
   v                                           [LEAVING] (3.5s delay)
[PONDERING]                                        |
                                                   v
                                                [GONE]
```

### 데드락 방지 안전 장치
1. **퇴근 타이머 취소 (Cancel Leaving)**: `turn_finish` 수신 후 엘리베이터로 이동하기 전 대기 시간(3.5초) 내에 새로운 이벤트가 유입되면 퇴근 동작을 즉시 취소하고 작업 모드로 복귀
2. **소멸 상태 복원 (Revive If Gone)**: `GONE` 상태의 캐릭터에 신규 이벤트가 도착할 경우 엘리베이터 게이트에서 즉시 재출근 처리하여 좌표 고착 방지
3. **이동 중 이벤트 큐잉**: `WALKING` 도중 사고(`thinking`)나 오류(`error`) 발생 시 보행을 중단하지 않고 말풍선만 갱신한 후 목적지 도착 시점에 상태 전이 완료
4. **다중 도구 병렬 추적**: `tool_use_id` 기반 셋(Set)으로 활성 도구를 추적하여 모든 비동기 작업이 완료된 시점에만 `WORKING` 상태 해제
5. **응답 지연 워치독**: 도구 결과 없이 설정된 임계 시간(기본 10분) 경과 시 캐릭터를 강제 종료하지 않고 "응답 대기 중..." 안내 말풍선을 출력하여 관찰자에게 상황 전달

## 보안 정책 및 프라이버시 보호

### 1. 로컬 루프백 전용 바인딩
- 서버 소켓은 외부 인터페이스(`0.0.0.0`)를 차단하고 오직 `127.0.0.1`에만 바인딩됩니다.
- 모든 수신 HTTP 요청의 `Host` 헤더를 검증하여 비인가 도메인을 통한 DNS Rebinding 공격을 원천 차단합니다.

### 2. 다계층 민감 정보 마스킹 (Secret Masking)
- 도구 호출 파라미터(`args`, `input`, `CommandLine`) 파싱 시 재귀 객체 순회(깊이 제한 적용)를 수행합니다.
- 키 명칭 기반: `/token|secret|passw(or)?d|api[_-]?key|auth|credential|private[_-]?key/i` 정규식 매칭 시 값 유형과 무관하게 `***` 치환
- 문자열 패턴 기반: Bearer 토큰, JWT(`eyJ...`), AWS 액세스 키(`AKIA...`), SSH/RSA 개인키 블록, URL 인라인 자격증명(`https://user:pass@...`) 자동 마스킹
- 전광판 및 상태 배지에 출력되는 문자열은 클라이언트로 전송되기 전 백엔드 단계에서 사전에 마스킹됩니다.

### 3. 파일 시스템 읽기 전용 스트리밍
- 대상 로그 파일은 `fs.openSync(..., 'r')` 읽기 전용 플래그로만 접근하며, 소스 파일에 대한 수정 권한을 요청하거나 행사하지 않습니다.

## 성능 최적화 명세

1. **복도 바닥 오프스크린 베이킹**:
   - 매 프레임 1,680회 수행되던 체커보드 디더링 루프를 서비스 기동 시 1회 사전 렌더링하고 `drawImage` 1회 호출로 대체하여 배경 렌더링 소요 시간을 **82.8% 단축** (0.373ms -> 0.064ms)
2. **배지 텍스트 말줄임 LRU 캐시**:
   - `drawBadgeLabel`의 `measureText` 기반 말줄임 연산 결과를 `(text, maxW)` 키 기반 LRU 캐시(최대 200개)로 관리하여 연산 부하를 **83.8% 단축** (0.0272ms -> 0.0044ms)
3. **사이드바 층 목록 Diff 갱신**:
   - 전체 DOM innerHTML을 재생성하지 않고 변경된 카드 요소의 클래스 및 텍스트만 선별 갱신하여 사이드바 리플로우 비용을 **62.8% 절감**
4. **대용량 파일 메모리 보호 스트리밍**:
   - 누적 토큰 초기 집계 시 전체 파일을 메모리에 적재하지 않고 1MB 청크 단위의 비동기 스트림 읽기와 개행 바이트(`0x0A`) 버퍼 파싱을 수행하여 수백 MB 로그 환경에서도 안정적인 힙 메모리 유지
